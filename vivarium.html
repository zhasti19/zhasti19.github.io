Mini Vivarium

A simplified multi-scale biological simulation framework

What is Mini Vivarium?

Vivarium is an open-source framework that lets scientists build biological models by composing many smaller simulations together, just as living cells combine dozens of overlapping processes—metabolism, gene expression, growth, signaling—each running on its own time scale.

Mini Vivarium is a lightweight JavaScript implementation of the same core ideas. You define independent processes, connect them through a shared store via typed ports, and group them into compartments. A central Vivarium object drives the whole simulation, firing each process at exactly its own time step while keeping all shared variables synchronized.

Key Concepts

📦 Store

A hierarchical key–value tree that holds all simulation state. Processes read and write the store through port mappings—never directly to each other.

🔌 Ports

Each process declares a port map: a dictionary linking local variable names to paths in the store. Ports are how simulations share variables without tight coupling.

⚙️ Process

A unit of computation with its own timeStep. Override next(inputs, dt) to implement any dynamics—ODE, stochastic, rule-based, or lookup table.

📁 Compartment

A named container that groups related initial state and processes under a shared namespace in the store (e.g. metabolism, nucleus). Compartments can be nested.

🔬 Vivarium

The top-level composer. It merges all compartments and processes, drives the event loop (smallest next time step first), and records a history of any tracked variables.

How to Use Mini Vivarium

Include vivarium.js in your page, then define process subclasses and compose them into a Vivarium. The full API is available via window.MiniVivarium. 

// 1.  Include the library
// <script src="vivarium.js"></script>

const { Store, Process, Compartment, Vivarium } = window.MiniVivarium;

// ── 2.  Define processes ─────────────────────────────────────────

class CellGrowth extends Process {
  constructor() {
    super({
      name: 'CellGrowth',
      ports: {
        volume: ['cell', 'volume'],   // port name → store path
        atp:    ['metabolism', 'atp'],
      },
      timeStep: 1.0                      // fires every 1.0 min
    });
    this.muMax = 0.015;  // max growth rate (min⁻¹)
    this.kAtp  = 1.0;    // ATP half-saturation (mM)
  }

  next(inputs, dt) {
    const mu = this.muMax * inputs.atp / (this.kAtp + inputs.atp);
    return { volume: inputs.volume * (1 + mu * dt) };
  }
}

class Metabolism extends Process {
  constructor() {
    super({
      name: 'Metabolism',
      ports: {
        glucose: ['metabolism', 'glucose'],
        atp:     ['metabolism', 'atp'],
        lactate: ['metabolism', 'lactate'],
      },
      timeStep: 0.5                      // faster – metabolic reactions
    });
  }

  next(inputs, dt) {
    const vGlu = 0.5 * inputs.glucose / (1.0 + inputs.glucose);
    return {
      glucose: Math.max(0, inputs.glucose - vGlu * dt),
      atp:     Math.max(0, inputs.atp + (2.0 * vGlu - 0.2) * dt),
      lactate: inputs.lactate + 2.0 * vGlu * dt,
    };
  }
}

// ── 3.  Compose with Compartments ───────────────────────────────

const cellComp = new Compartment({
  name: 'cell',
  initialState: { volume: 1.0 },
  processes: [new CellGrowth()],
});

const metComp = new Compartment({
  name: 'metabolism',
  initialState: { glucose: 10.0, atp: 2.0, lactate: 0.0 },
  processes: [new Metabolism()],
});

const sim = new Vivarium({
  compartments: [cellComp, metComp],
  trackPaths: [
    ['cell', 'volume'],
    ['metabolism', 'atp'],
  ],
});

// ── 4.  Run ──────────────────────────────────────────────────────

const history = sim.run(60);       // simulate 60 minutes
console.log(history.time);           // [0, 0.5, 1.0, 1.5, ...]
console.log(history['cell.volume']); // [1.0, 1.01, ...]

API Reference

Store

MethodDescription
new Store(initialState) Create a store with an optional initial state object.
store.get(path) Read a value at the given path array, e.g. ['cell', 'volume'].
store.set(path, value) Write a value into the store.
store.getState() Return a deep copy of the full state tree.

Process

MemberDescription
constructor({ name, ports, timeStep }) Declare the process name, port map, and time step.
next(inputs, dt) → updates Override to compute the next state. Return an object with updated port values.
initialState() Optional override: return initial state contributions merged into the store.

Compartment

MemberDescription
new Compartment({ name, initialState, processes }) Bundle state and processes under a shared namespace.

Vivarium

MethodDescription
new Vivarium({ state, compartments, processes, trackPaths }) Create a composer. Supply top-level state, compartments, loose processes, and an array of store paths to record.
sim.step() Advance by exactly one event (the process with the earliest next run time).
sim.run(totalTime) Run for totalTime units. Returns the history object.
sim.getHistory() Return recorded history: { time: [...], 'path.key': [...] }.
sim.getState() Return the current full state of the store.
sim.time Current simulation time (read-only).
